# LuxuryStay Hospitality — Client

React 19 single-page application powered by Vite and Tailwind CSS v4.

## Scripts

| Command           | Purpose                        |
| ----------------- | ------------------------------ |
| `npm run dev`     | Start the Vite dev server on port 3000 |
| `npm run build`   | Production build into `dist/`  |
| `npm run preview` | Preview the production build   |
| `npm run lint`    | Run Oxlint                     |

API requests to `/api/*` are proxied to `http://localhost:5000` in development.
`react-router-dom` provides routing and `axios` is available for HTTP calls.
See the root [README](../README.md) for setup, environment variables, and conventions.
